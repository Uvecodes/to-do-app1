PWA Icons Required

This directory should contain the following PNG icon files for the PWA to work properly:

1. icon-192x192.png (192x192 pixels)
2. icon-512x512.png (512x512 pixels)

These icons are referenced in manifest.json. You can:
- Convert icon.svg (in root directory) to PNG format at these sizes
- Use an online tool or image editor to create these icons
- Ensure icons are optimized for PWA use

The PWA will not be fully installable until these icon files exist.
